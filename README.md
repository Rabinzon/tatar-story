# Әкиятләр китапханәсе

Сайт для чтения татарских народных сказок. Каждая сказка — один `.mdx`-файл;
всё остальное подчинено удобству чтения: спокойная колонка текста, книжная
типографика, тема по системе и настройки читателя.

## Стек

- **Astro** — статическая сборка, ноль JS-фреймворков на странице;
- **MDX** — тексты сказок с компонентами прямо в тексте;
- **@fontsource** — самостоятельно размещённые шрифты, без запросов к чужим CDN.

Шрифты: **Alegreya** (заголовки), **Literata** (текст), **Golos Text**
(интерфейс). Все три перекрывают татарскую кириллицу — ә, ө, ү, җ, ң, һ —
подмены глифов не происходит.

## Команды

```bash
npm install
npm run dev       # http://localhost:4321
npm run build     # сборка в dist/
npm run preview   # посмотреть собранное
```

## Как добавить сказку

Создайте `src/content/tales/<slug>.mdx` — адрес страницы совпадает с именем файла.

```mdx
---
title: "Өч кыз"              # название на татарском
titleRu: "Три дочери"        # русское название, подзаголовок
kind: "халык әкияте"         # жанровая помета
tags: ["tylsymly"]           # ключи фильтров, см. src/lib/tags.ts
summary: "Одна фраза для карточки в списке."
source: "Издание, по которому подготовлен текст"
featured: false              # true — крупная карточка «Атна әкияте»
order: 7                     # меньше — выше в списке
---

Борын-борын заманда <Gloss ru="белка">тиен</Gloss> яшәгән…

<Sep />

<Note>Тиен — әкиятләрдә хәбәрче.</Note>
```

Компоненты доступны без импорта:

| Компонент | Назначение |
| --- | --- |
| `<Gloss ru="перевод">сүз</Gloss>` | слово с переводом: пунктир, тап или фокус с клавиатуры |
| `<Sep />` | тюльпан-разделитель сцены |
| `<Note>…</Note>` | примечание редактора |
| `<Verse>…</Verse>` | строфы: каждая строка — отдельный абзац |

Абзацы, начинающиеся с тире, автоматически получают книжную выключку реплики —
классы руками расставлять не нужно (`src/plugins/rehype-dialogue.mjs`).

Время чтения и число слов считаются при сборке из самого текста
(`src/lib/reading.ts`), в фронтматтере их указывать не надо.

## Настройки читателя

Тема (авто / светлая / тёмная), кегль, ширина строки и гарнитура хранятся в
`localStorage` и применяются до первой отрисовки — страница не моргает. Тема по
умолчанию следует за системной.

## Деплой

`.github/workflows/deploy.yml` собирает сайт и публикует на GitHub Pages при
пуше. Домен и подпапка передаются сборке через `SITE_URL` и `BASE_PATH`, поэтому
сайт одинаково работает и в корне домена, и в `/<repo>/`. Если в настройках
репозитория Pages ещё не включены, откройте **Settings → Pages** и выберите
источник **GitHub Actions**.

## О текстах

Сказки в репозитории — пересказы для демонстрации вёрстки. Перед публикацией их
нужно заменить выверенными текстами по печатным изданиям и указать источник в
поле `source` каждой сказки.
